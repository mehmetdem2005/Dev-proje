# Crownfall: Army Dominion

Native Android/Kotlin real-time strategy game inspired by large-army medieval `.io` games. No web runtime, HTML, JavaScript, WebView, Lordz.io branding, or copied proprietary assets are used.

The application uses a custom Android rendering/game loop, touch joystick, camera, economy, recruitable armies, structures, combat AI, bot kingdoms, minimap, victory and defeat states.
